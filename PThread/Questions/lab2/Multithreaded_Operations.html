Exercise: Implementing Multithreaded Operations

Objective

The primary goal of this exercise is to become familiar with core PThreads operations, including creation, joining, and exiting (passing arguments). You will implement functions that calculate the factorial of a number, and find the minimum and maximum values in an array. Results must be returned to the main function through thread exits or shared memory.

Requirements

  • Shared Data: An integer X and an integer array arr of size N, both populated by user input.
  • factorial(): Calculates the factorial of X and exits with the result.
  • min(): Finds the minimum value in arr and exits with the result.
  • max(): Finds the maximum value in arr and exits with the result.
  • minMax(): Manages threads for min and max functions, stores their results, and exits with the combined data.

Exercise 1: Parallel Array Processing

Problem: Process a large array using multiple threads, where each thread processes a portion of the array.

Sequential Code (Provided):

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define ARRAY_SIZE 1000000

void processArray(int *array, int size) {
    for (int i = 0; i < size; i++) {
        array[i] = array[i] * array[i] + 1; // Some computation
    }
}

int main() {
    int *array = (int*)malloc(ARRAY_SIZE * sizeof(int));
    
    // Initialize array
    for (int i = 0; i < ARRAY_SIZE; i++) {
        array[i] = i;
    }
    
    clock_t start = clock();
    processArray(array, ARRAY_SIZE);
    clock_t end = clock();
    
    double time_taken = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("Time taken: %f seconds\n", time_taken);
    
    free(array);
    return 0;
}

Your Task:

  1. Create multiple threads using pthread_create()
  2. Divide the array among threads (each thread processes a chunk)
  3. Use a structure to pass thread parameters (start index, end index, array pointer)
  4. Wait for all threads to complete using pthread_join()
  5. Measure and compare execution time
Hints:
  • Include <pthread.h> header
  • Compile with -pthread flag: gcc -pthread program.c -o program
  • Create a struct to pass data to each thread: 
    typedef struct {
    int start;
    int end;
    int *array;
} thread_data_t;
  • Thread function signature: void* threadFunction(void* arg)

Exercise 2: Parallel Dot Product with Synchronization

Problem: Calculate the dot product of two vectors using multiple threads. Use mutex to protect the shared sum variable.

Sequential Code (Provided):

#include <stdio.h>
#include <stdlib.h>

#define VECTOR_SIZE 1000000

double dotProduct(double *a, double *b, int size) {
    double sum = 0.0;
    for (int i = 0; i < size; i++) {
        sum += a[i] * b[i];
    }
    return sum;
}

int main() {
    double *a = (double*)malloc(VECTOR_SIZE * sizeof(double));
    double *b = (double*)malloc(VECTOR_SIZE * sizeof(double));
    
    // Initialize vectors
    for (int i = 0; i < VECTOR_SIZE; i++) {
        a[i] = 1.0;
        b[i] = 2.0;
    }
    
    double result = dotProduct(a, b, VECTOR_SIZE);
    printf("Dot product: %f\n", result);
    
    free(a);
    free(b);
    return 0;
}

Your Task:

  1. Create multiple threads, each computing a partial dot product
  2. Use a mutex to protect the shared sum variable when adding partial results
  3. Initialize the mutex with pthread_mutex_init()
  4. Lock before updating sum, unlock after
  5. Destroy the mutex with pthread_mutex_destroy()
  6. Compare with a version that uses local variables and combines at the end (better approach)
💡 Multiple Approaches:
  • Option 1: Use mutex to protect shared sum (simple but has lock contention)
  • Option 2: Each thread computes local sum, then add to global sum once (better performance, less contention)

Implement both approaches and measure the performance difference - Option 2 is significantly faster!

Hints:
  • Declare mutex: pthread_mutex_t mutex;
  • Initialize: pthread_mutex_init(&mutex, NULL);
  • Lock: pthread_mutex_lock(&mutex);
  • Unlock: pthread_mutex_unlock(&mutex);
  • Better approach: Each thread computes local sum, then add to global sum once (reduces lock contention)

Exercise 4: Parallel Matrix Multiplication

Problem: Multiply two matrices using multiple threads, where each thread computes a set of rows of the result matrix.

Sequential Code (Provided):

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define SIZE 1000

void matrixMultiply(int **A, int **B, int **C, int size) {
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            C[i][j] = 0;
            for (int k = 0; k < size; k++) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }
}

int main() {
    // Allocate matrices
    int **A = (int**)malloc(SIZE * sizeof(int*));
    int **B = (int**)malloc(SIZE * sizeof(int*));
    int **C = (int**)malloc(SIZE * sizeof(int*));
    
    for (int i = 0; i < SIZE; i++) {
        A[i] = (int*)malloc(SIZE * sizeof(int));
        B[i] = (int*)malloc(SIZE * sizeof(int));
        C[i] = (int*)malloc(SIZE * sizeof(int));
    }
    
    // Initialize matrices
    for (int i = 0; i < SIZE; i++) {
        for (int j = 0; j < SIZE; j++) {
            A[i][j] = i + j;
            B[i][j] = i * j;
        }
    }
    
    clock_t start = clock();
    matrixMultiply(A, B, C, SIZE);
    clock_t end = clock();
    
    double time_taken = ((double)(end - start)) / CLOCKS_PER_SEC;
    printf("Time taken: %f seconds\n", time_taken);
    
    // Free memory
    for (int i = 0; i < SIZE; i++) {
        free(A[i]);
        free(B[i]);
        free(C[i]);
    }
    free(A);
    free(B);
    free(C);
    
    return 0;
}

Your Task:

  1. Create multiple threads, each computing a range of rows
  2. Use a structure to pass thread parameters (start row, end row, matrices)
  3. No synchronization needed (each thread writes to different rows)
  4. Join all threads and measure performance
  5. Compare with sequential version
💡 Multiple Approaches:
  • Division Strategy: Row-based (each thread computes several rows) or Block-based (each thread computes a rectangular block)
  • Work Distribution: Static (equal chunks) or Dynamic (work-stealing approach)

Try both row-based and block-based division to see which performs better on your system!

Hints:
  • Calculate rows per thread: rows_per_thread = SIZE / num_threads
  • Thread i computes rows from i * rows_per_thread to (i+1) * rows_per_thread - 1
  • No mutex needed since threads don't share write locations

Exercise 5: Reader-Writer Problem with Read-Write Locks

Problem: Implement a reader-writer scenario where multiple readers can read simultaneously, but writers need exclusive access.

Sequential Code (Provided - Template):

#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

int shared_data = 0;
int reader_count = 0;

// TODO: Add read-write lock

void* reader(void *arg) {
    int id = *((int*)arg);
    // Acquire read lock
    // Read shared_data
    printf("Reader %d read: %d\n", id, shared_data);
    // Release read lock
    return NULL;
}

void* writer(void *arg) {
    int id = *((int*)arg);
    // Acquire write lock
    // Write to shared_data
    shared_data++;
    printf("Writer %d wrote: %d\n", id, shared_data);
    // Release write lock
    return NULL;
}

int main() {
    // Create multiple reader and writer threads
    return 0;
}

Your Task:

  1. Use pthread_rwlock_t for read-write synchronization
  2. Readers use pthread_rwlock_rdlock()
  3. Writers use pthread_rwlock_wrlock()
  4. All use pthread_rwlock_unlock() to release
  5. Initialize and destroy the read-write lock properly
  6. Test with multiple readers and writers
Hints:
  • Declare: pthread_rwlock_t rwlock;
  • Initialize: pthread_rwlock_init(&rwlock, NULL);
  • Read lock: pthread_rwlock_rdlock(&rwlock);
  • Write lock: pthread_rwlock_wrlock(&rwlock);
  • Unlock: pthread_rwlock_unlock(&rwlock);

Compilation Instructions
